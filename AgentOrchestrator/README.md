# AgentOrchestrator 🤖

Локальная многоагентная система автоматизации разработки и редизайна проектов. Она координирует четырех специализированных агентов для планирования, проектирования интерфейсов, написания кода и тестирования.

## Как работают агенты:
1. **DesignerAgent (Дизайнер):** Исследует веб-тренды дизайна для вашей задачи, собирает палитры и приемы UX с помощью поиска Google.
2. **PlannerAgent (Планировщик):** Строит пошаговую архитектуру изменений на основе структуры проекта.
3. **CoderAgent (Разработчик):** Реализует конкретные шаги с помощью точечных `SEARCH/REPLACE` блоков.
4. **VerifierAgent (Тестировщик):** Локально проверяет код и помогает исправить ошибки в случае сбоя сборки или тестов.

## Настройка и Запуск

### 1. Перейдите в папку утилиты:
```bash
cd AgentOrchestrator
```

### 2. Настройте файл окружения `.env`:
Создайте файл `.env` в этой папке и запишите ваш Gemini API Ключ:
```env
GEMINI_API_KEY=ваш_api_ключ_здесь
```

### 3. Запустите скрипт:
В зависимости от вашей операционной системы, активируйте виртуальное окружение и запустите координатор:

**На Windows (PowerShell):**
```powershell
.venv\Scripts\activate
python orchestrator.py
```

**На macOS / Linux (Terminal):**
```bash
source .venv/bin/activate
python orchestrator.py
```

---

## Безопасность прежде всего 🛡️
Агенты **не вносят изменения напрямую в файлы без вашего разрешения**.
Перед каждой записью на диск на экране отображается красивый `diff` изменений, и утилита запрашивает интерактивное подтверждение (`[y/N]`).
